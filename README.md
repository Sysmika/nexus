# Nexus by Orion · repositorio de add-ons para Home Assistant

Add-on **Nexus by Orion**: convierte un Home Assistant OS en Nexus (marca, PWA, módulo de Soporte con tickets en Orion y dashboard de entrada).

## Instalar
1. En Home Assistant: **Ajustes → Add-ons → Tienda de add-ons → ⋮ → Repositorios**.
2. Agregar la dirección de este repositorio.
3. Instalar **Nexus by Orion**, pegar el código de instalación (se genera en Orion) e iniciar.

Nexus funciona sobre [Home Assistant](https://www.home-assistant.io/) (Open Home Foundation, licencia Apache 2.0). Incluye las tarjetas `card-mod` y `button-card` (licencia MIT) de sus autores.
